Cara Menjalankan Website di CMD

Panduan langkah demi langkah untuk membuka file website ini melalui Command Prompt (CMD)

1

Simpan File Website

Simpan kode di atas dengan nama file raisya_portfolio.html di dalam folder komputer Anda (misalnya di folder C:\Users\Raisya\Website).

2

Buka Command Prompt (CMD)

Tekan tombol Windows + R pada keyboard, ketik cmd lalu tekan Enter.

3

Masuk ke Direktori Folder File

Ketik perintah perpindahan folder pada CMD sesuai letak file Anda tersimpan, contoh:

C:\Users> cd Documents\Website
4

Jalankan File di Browser

Ketik nama file untuk membukanya secara langsung melalui browser default komputer Anda:

raisya_portfolio.html
